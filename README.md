# Recipe CRUD API (Node.js & MongoDB)

## Setup & Run

1. Clone the repo and navigate to the project folder.
2. Install dependencies:
   npm install
3. Create a `.env` file with:
   MONGO_URI=<your_mongodb_connection_string>
   PORT=3100
4. Start server (with nodemon):
   npm run dev

Server runs at: http://localhost:3100

## Postman Collection

Use the attached Postman collection to test all APIs:

- Create Recipe
- List Recipes
- Get Recipe by ID
- Dynamic Ingredients by Serves
- Update Status
- Delete Recipe
